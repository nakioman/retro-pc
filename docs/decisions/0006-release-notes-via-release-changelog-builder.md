# 0006. Release notes via release-changelog-builder, drop hand-maintained CHANGELOG.md

Date: 2026-08-25
Status: Accepted

## Context

The hand-maintained `CHANGELOG.md` drifted because `[Unreleased]` discipline
wasn't enforced on PRs; releases were tagged but the `CHANGELOG.md` had to be
hand-edited to move `[Unreleased]` to a dated section, which got missed.

## Decision

Delete `CHANGELOG.md`. Release notes for the GitHub Release are generated by
`mikepenz/release-changelog-builder-action@v6` in COMMIT mode against the
previous tag, grouped by Conventional Commit type. No PR check, no
`[Unreleased]` discipline.

## Consequences

- Contributors no longer need to update `CHANGELOG.md`. Conventional Commit
  messages become the source of truth.
- Historical releases before this change are still discoverable as GitHub
  Releases (the tag → release mapping is unchanged). The `CHANGELOG.md` file is
  deleted, breaking any deep-link references — none exist in this repo outside
  the doc map / process rules, all of which are updated in this PR.
- The release job gains an external dependency
  (`mikepenz/release-changelog-builder-action@v6`). It is well-maintained
  (v6.2.3 in June 2026, 863 stars) and read-only in COMMIT mode.
- If we ever adopt semver tags, the same action can switch to default tag
  resolution.
