    Acerca de RetroBox

    Administración de disquetes NFC y máquinas virtuales 86Box.

    Mockup de escritorio con estética Windows 3.1. Todas las operaciones son simuladas y se descartan al recargar.

    Usá las pestañas para navegar y Escape para cerrar un diálogo. El archivo README.md acompaña este prototipo con los flujos y el alcance de implementación.
