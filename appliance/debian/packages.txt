# Debian 13 (trixie) runtime package manifest for the Retro PC appliance.
#
# This list is intentionally limited to packages needed by the physical
# appliance at runtime and for normal maintenance. It is suitable as the
# explicit package list layered on top of a minimal Debian 13 installation.
# Dependency packages pulled in by APT are not listed separately.
#
# The official debian:13-slim image is a useful reference for keeping the
# starting point small, but the final target is a physical Debian system with
# systemd, hardware devices, SSH, Samba, and audio support.

# Base service/runtime
systemd
systemd-sysv
udev
linux-image-amd64
grub-pc-bin

# Appliance administration and file transfer
openssh-server
samba
sudo
network-manager

# Hardware and audio runtime.  The generic Debian kernel intentionally carries
# modules for many machines; that is one package, not a desktop or vendor
# driver installation.
alsa-utils
kmod
fuse3
libgl1
libasound2t64
libpulse0

# Small maintenance/networking toolset
procps
iproute2
util-linux
pciutils
ca-certificates

# Deliberately excluded from this base manifest:
# - .NET SDK, compilers, and build tools
# - Docker or container tooling
# - desktop environments and window managers
# - DOS, Windows, drivers, games, or other copyrighted media
#
# 86Box is supplied as an AppImage. It is launched directly on the BIOS
# console, so an X server, display manager, desktop environment, and X11
# session tools are deliberately not part of the appliance.
